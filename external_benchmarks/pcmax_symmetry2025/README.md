# P||Cmax Instances

The instances are described in https://doi.org/10.3390/sym17020178.

There are four standardized types of instances: B, C, E, and F. For groups E and B instances have been generated by us using a random seed of 1. We have included the generator codes for reference. Additionally, the file 'Results_iAF.xlsx' contains the iAF [1] solver results for these instances, for timelimit of 1200s.

For every class of C and F instances CPLEX results are provided in .zip files.

[1] Gharbi, Anis, and Khaled Bamatraf. "An improved arc flow model with enhanced bounds for minimizing the makespan in identical parallel machine scheduling." Processes 10.11 (2022): 2293.
